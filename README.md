# 深空当铺 · AI 店主 MCP

这是《深空当铺：可能是偷的》的社区公测项目。DeepSeek Harness 可以用文字读取当铺状态，选择展示商品与进货灯牌，和当前客人成交，也可以用工具鉴定物品、操作设备或带包外出。欢迎在自己的副本上发现问题。

## 开始公测

1. 在[版本下载页](https://github.com/Arom-corgi/pawnshop-harness-mcp/releases)选择同一版的游戏模组和 `pawnshop-harness-client-windows.zip`。使用工坊版时只需另外下载客户端。
2. 在游戏里启用模组并重启。将客户端 ZIP 解压到游戏目录之外，在装有 Python 3.11 或更新版本的 Windows 电脑上双击 `install-client.cmd`。
3. 在 DeepSeek Harness 中重新连接 MCP。可以先说「查看我的存档、日期和现金，读出一件灯牌的功能说明」。核对档位后再让 AI 开始营业。

## 参与测试

如果遇到问题，欢迎[提交 BUG](https://github.com/Arom-corgi/pawnshop-harness-mcp/issues/new/choose)。安装失败、某个窗口关不掉、成交后只卖出部分商品，都是值得记录的情况。请写上版本，以及操作前后实际发生了什么。物品已经移动、现金已经变化时，保留现场即可。
